# Guide AI Bot

Telegram-бот для генерации и прохождения тестов с использованием ИИ.

## Описание проекта

Guide AI Bot - это Telegram-бот, который позволяет пользователям:
- Создавать и проходить тесты с использованием искусственного интеллекта
- Пользоваться системой баланса и оплаты
- Администрировать через веб-панель

## Технологии

- Python 3.8+
- aiogram 3.x
- SQLAlchemy
- FastAPI
- SQLite (или PostgreSQL в продакшене)
- Alembic (для миграций БД)

## Установка и настройка

1. Клонируйте репозиторий:
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd guide_ai
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте переменные окружения:
- Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
- Отредактируйте файл `.env`, добавив свои значения:
 - `BOT_TOKEN` - токен вашего Telegram-бота
  - `DATABASE_URL` - строка подключения к базе данных
  - `MISTRAL_API_KEY` - API ключ для Mistral AI
  - `OPENROUTER_API_KEY` - API ключ для OpenRouter
  - и другие настройки по необходимости

4. Запустите миграции базы данных:
```bash
python -m alembic upgrade head
```

5. Запустите бота:
```bash
python run.py
```

## Настройка AI-провайдеров

Проект поддерживает несколько провайдеров ИИ:
- Mistral AI
- OpenRouter
- Другие (через базовый класс)

Для настройки добавьте соответствующие API-ключи в файл `.env`.

## Администрирование

Админ-панель доступна по умолчанию по пути `/admin` веб-приложения. Для доступа используйте учетные данные, указанные в файле `.env`.

## Вебхуки

Для приема платежей через Robokassa настроены вебхуки. Убедитесь, что ваш сервер доступен из интернета и настроены соответствующие URL в настройках Robokassa.

## Развертывание

В папке `deploy/` находятся скрипты для развертывания на различных платформах:
- Apache
- Скрипты настройки базы данных
- Установка зависимостей

## Безопасность

- Не храните чувствительные данные в репозитории
- Используйте файл `.env` для хранения секретов
- Регулярно обновляйте зависимости
- Проверяйте права доступа к админ-панели
